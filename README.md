# Java DSA Placement Training

This repository contains my Java programs and problem-solving practice completed during a 12-day placement training program.

## Training Progress

### Day 1: Conditional Statements

- Calculator and switch-case problems
- Prime, even/odd, weekday, marks, and number-based problems

### Day 2: Loops

- Factorial and number problems
- Prime numbers in a range
- Perfect, neon, and special numbers
- Pattern programs using nested loops

### Day 3: Arrays

- One-dimensional, two-dimensional, and three-dimensional arrays
- Array sorting and distinct elements
- Matrix and sum-based problems

### Day 4: Strings

- String reversal and palindrome checking
- Vowel and character counting
- Substring and string sorting problems
- Non-repeating characters

### Day 5: Object-Oriented Programming

- Classes and constructors
- Inheritance
- Method overloading and overriding
- Polymorphism
- Matrix transpose

### Days 6-8: Linked Lists

- Singly linked lists
- Doubly linked lists
- Circular and doubly circular linked lists
- Insertion, deletion, and traversal operations

### Day 9: Stacks

- Stack implementation using linked lists
- Stack traversal and reversal
- Valid parentheses and number-based problems

### Day 10: Queues

- Queue and circular queue implementation
- First unique element problem
- Matrix and number-based problems

### Day 11: Binary Trees

- Binary tree and binary search tree construction
- Inorder, preorder, and postorder traversals

### Day 12: Graphs

- Graph representation using adjacency matrices
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## Summary

- Completed 40+ Java programs
- Practiced core programming fundamentals and problem solving
- Implemented fundamental data structures from scratch
- Built a foundation for placement-focused DSA preparation
